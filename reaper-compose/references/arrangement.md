# アレンジの引き出し

ピアノのスケッチから曲を広げるときに参照するメモ。音名は C4=60(REAPER表記)。

## 分析の観点

ユーザーのMIDIを読んだら、次の順に見る。全部を話す必要はない。目立つ2〜3点を小節番号つきで伝える。

1. **調**: 推定の1位と2位(平行調)のどちらか。導音(マイナーなら♯5度)が出ているか。途中の転調・借用和音。
2. **コード進行と機能**: トニック(T)・サブドミナント(S)・ドミナント(D)の流れ。終止の形(V→I、IV→I、偽終止 V→vi)。
3. **ハーモニックリズム**: コードが何拍ごとに変わるか。セクションごとの違い。
4. **旋律**: 音域(最低音〜最高音)、ピークの位置、跳躍と順次進行の割合、繰り返されるモチーフ(リズムの型・音程の型)。
5. **リズム**: シンコペーション、アウフタクト、3連・スウィング、休符の使い方。
6. **左手の型**: ブロック、分散和音、オクターブ、ベースライン、アルペジオ。ペダルの踏み方。
7. **ボイシング**: 密集か開離か、トップノートの線、低音域の濁り(下の「ピアノのブラッシュアップ」)。
8. **フレーズの長さと構成**: 4小節・8小節の単位、問いと答え、どこがAメロ/サビ候補か。

## 広げ方

- **モチーフの展開**: 反復、移高(シーケンス)、リズムを保って音程を変える、音程を保ってリズムを変える、拡大・縮小、反行。
- **セクションの対比**(Aメロ → Bメロ → サビ):
  - 音域: サビで旋律の平均を3〜5度上げる。ピークはサビの後半に。
  - 密度: Aメロは音数を減らし、サビで声部を足す(パッド、オクターブ、対旋律)。
  - ハーモニックリズム: Bメロで速める(2拍ごと)と緊張が上がる。
  - コード: Aメロをトニックから、Bメロをサブドミナント(IVやii)から始めるとサビが立つ。
  - サビ頭のコード: I始まりは「着地」、IVmaj7始まりは「開放感」(王道進行)、vi始まりは「切なさ」。
- **転調**: 最後のサビで半音〜全音上げる(直前にVを置くか、ブレイクで飛ぶ)。平行調・同主調への行き来。
- **つなぎ**: セクション最後の1小節を、ベースの順次進行、ブレイク(全休止)、フィル、sus4→3度で作る。

## リハーモナイズ

| 手法 | 例(Cメジャー) | 効果・使いどころ |
|---|---|---|
| ダイアトニック代理 | C → Am / Em、F → Dm | 色を変える。旋律がコードトーンのまま残るか確かめる |
| セカンダリードミナント | Dm の前に A7、Am の前に E7 | 次のコードへの引力。サビ前・Bメロ |
| ツーファイブ化 | G7 → Dm7 G7 | 進行を細かくして推進力を出す |
| 裏コード | G7 → Db7 | ベースが半音で下がる(Db→C)。ジャズ・シティポップ |
| サブドミナントマイナー | F → Fm、Bb、Ab | 切なさ・懐かしさ。サビ終わりの F → Fm → C |
| パッシングディミニッシュ | C → C#dim → Dm | ベースを半音で上げる |
| 分数コード・順次ベース | C → G/B → Am → Am/G → F | 滑らかで大きな流れ(カノン進行の変形) |
| ペダルポイント | ベースをCに固定して上を C → F/C → G/C | 期待を引き伸ばす。イントロ・Bメロ |
| sus4 | G7sus4 → G7 | 解決を遅らせる |
| テンション | Cmaj7、Cadd9、Dm9、G13 | 響きを都会的に。旋律と半音でぶつからないか確かめる |

よく知られた進行(ユーザーとの共通語として使える):

- 王道進行: IVmaj7 → V7 → iiim7 → vim7(F → G → Em → Am)
- カノン進行: I → V/7 → vi → iii/5 → IV → I/3 → IV → V
- 小室進行: vim → IV → V → I
- 丸サ進行(Just the Two of Us): IVmaj7 → III7 → vim7 → v m7 → I7
- 循環: I → vi → ii → V

## パートごとの作り方

### ベース(エレキベースの実音: E1〜G3 くらい)

- 基本はルート。コードの変わり目の直前に**経過音・半音のアプローチ**(下から/上から)を置くと流れが出る。
- 刻みでジャンルが決まる: バラードは全音符〜2分、ポップは8分、ファンク・シティポップは16分のシンコペーション。
- キックとリズムを合わせる(ドラムを書くときは両方を見比べる)。
- ピアノの左手とぶつけない: ピアノがベースを弾いているなら、ピアノの左手を1オクターブ上げる提案もする。
- GM: 33 Fingered、34 Picked、35 Fretless、38 Synth Bass、32 Acoustic(ウッド)。

### ドラム(ch 10、GM)

- 8ビート: キック 1・3拍(+3拍の裏)、スネア 2・4拍、ハイハット8分(表 vel 90前後、裏 65前後)。
- バラード: ハイハットかライドを4分〜8分で薄く、キックは少なめ、スネアはサイドスティックから。
- 16ビート: ハイハット16分(強弱をはっきり)、キックにシンコペーション。
- シャッフル・6/8: ハイハットを3連の頭と3つ目で、または8分を6つ。
- セクション頭にクラッシュ、終わりの1〜2拍にフィル(タム高→低、スネアの連打)。
- 音名は `references/gm.md` のドラム表。ドラムはタイミングを揃え、ベロシティで表情を付ける。

### パッド・ストリングス

- 中音域(C3〜C5)に密集配置で置き、**共通音は保持、ほかは最小移動**(ボイスリーディング)。
- ピアノの右手と同じ音域・同じリズムに重ねない。ピアノが動くところでは伸ばす。
- サビで上に1声足す、オクターブ上げる、ストリングスを開離配置にして広げる。
- 弦楽器の目安(実音): Vn G3〜E6、Va C3〜E5、Vc C2〜A4、Cb E1〜G3(Cbの楽譜は1オクターブ上に書くが、MIDIは実音で書く)。
- GM: 48 Strings、49 Slow Strings、89 Warm Pad、91 Choir Pad、52 Choir Aahs。

### 対旋律・オブリガート

- 主旋律が伸ばしている・休んでいる所で動き、主旋律が動く所では伸ばす(コール&レスポンス)。
- 主旋律と反行させるか、3度・6度で平行させる。オクターブと完全5度の連続は避ける。
- 音域を分ける(主旋律の上か、1オクターブ下)。
- GM: 73 Flute、71 Clarinet、65 Alto Sax、11 Vibraphone、4 E.Piano。

### ピアノのブラッシュアップ

- **低音域の濁り**: おおむねC3より下では3度・2度を重ねない。オクターブ、5度、10度に開く。
- **トップノート**: 右手の和音の一番上の音が線になるように並べる(上声部の順次進行)。
- **ボイシング**: 7th・9thを足すときは、ルートを左手、3度と7度を右手の内声に置くと濁りにくい。
- **ペダル**: コードが変わった**直後**に踏み替える(押し上げてすぐ踏む)。コードの変わり目をまたいで踏みっぱなしにしない。
- **ベロシティの抑揚**: フレーズの山に向けて上げ、終わりで下げる。内声は外声より少し弱く。
- **クオンタイズ**: 機械的に揃えすぎない。直すなら「ずれが大きい所だけ」「強さ50%」など、ユーザーと程度を決める。

## 人間らしさ

- ベロシティ: 同じ音型でも±5〜12揺らす。拍の頭を強く、裏を弱く。フレーズの頂点に最大値。
- タイミング: ドラム以外は±0.01〜0.02拍の揺れ(120BPMで±5〜10ms)を入れてもよい。ドラムは揃える。
- 長さ: レガートは次の音の直前まで(長さ×0.95〜1.0)、スタッカートは半分以下。ベースのミュート感は長さ×0.6〜0.8。
- 同じ小節の繰り返しでも、4小節目・8小節目で少し変える(経過音、リズムの変化、フィル)。

## 音色とミックス(Claudeは聴けないので、ユーザーの言葉を手がかりにする)

- 「こもる」: 低中域(200〜500Hz)が多い。パッドやピアノの左手の音域を上げる、パッドのローカットを提案する。
- 「埋もれる」: 同じ音域・同じリズムのパートがある。音域かリズムをずらす。
- 「うるさい」: 音数・ベロシティ・高域のどれか。まず音数を減らす。
- 音量の初期値: ドラムとベースを基準に、パッドは−6〜−10dB、対旋律は主旋律より控えめに。
